# AGENTS.md — Regras de Colaboração para Agentes de IA

1. Este projeto pertence a Allan Candido.
2. Jamais incluir menções de co-autoria a agentes de IA em commits ou documentação.
3. Não use bibliotecas visuais genéricas ou designs escuros. O tema é claro, quente, com textura de papel e fidelidade à paisagem litorânea de Aquiraz.
4. Mantenha os tokens de CSS centralizados no `globals.css`.
5. Antes de qualquer commit, valide a compilação com `npm run build`.
